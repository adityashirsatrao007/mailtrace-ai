## UI/UX Overhaul (Latest Session)
- **Typography**: Inter + JetBrains Mono loaded from Google Fonts with preconnect
- **Type Scale**: Minor Third (1.2 ratio) — H1 28px, H2 20px, H3 15px, Body 14px, Caption 12px, Label 11px
- **Tabular numerals**: `font-variant-numeric: tabular-nums` on all data/monospace text
- **Color system**: 4-level surface elevation (dark-950 → dark-800), off-white text (#f1f5f9), never pure white
- **Dark theme**: Base #020617, cards #0f172a/0.5 glass, borders rgba(255,255,255,0.06)
- **Animations**: Staggered fade-in, slide-in, scale-in, count-up. All respect `prefers-reduced-motion`
- **Sidebar**: Active state with left indicator bar, hover transitions, section labels
- **Cards**: Glass with backdrop-filter blur(16px), hover lift (-2px translateY), subtle border glow
- **Buttons**: Primary gradient, secondary ghost, all with cubic-bezier easing
- **Inputs**: Focus ring with 3px spread, placeholder styling
- **Tables**: Sticky headers, row hover, tabular numerals, monospace data cells
- **Badges**: Pill-shaped with alpha backgrounds, not solid fills
- **Progress bars**: Smooth width transitions
- **Loading spinner**: CSS-only in index.html (no FOUC)
- **Scrollbar**: Custom webkit scrollbar (6px)
- **Selection**: Blue highlight matching theme
